# 南下去过冬 · 手机旅行手账

2026/12/25—2027/01/03，深圳、香港、槟城与马来西亚的 10 日旅行攻略。纯静态页面，无须安装依赖或编译。

## 本地运行

在仓库根目录执行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

## 手机端结构

- **行程**：每日时间轴、交通导航、餐饮与可展开的景点攻略。
- **地图**：按日期查看手绘图，支持全屏缩放与 PNG 导出。
- **发现**：主行程之外的备选景点、餐厅，支持城市筛选和搜索。
- **预算**：两人人民币预算，修改金额后自动汇总。
- **准备**：航班、住宿方案、按时间线或类别排列的待确认事项与可勾选的行李清单。

采用统一的手机布局，大屏浏览时也保持窄版阅读。酒店切换会更新关联行程和餐费。酒店选择、预算、待办和行李勾选保存在当前浏览器的 localStorage。

## GitHub Pages 发布

发布文件包括 `index.html`、`mobile.css`、`confirmations.js` 和 `maps/`，须保持相对目录不变。

仓库 Settings → Pages → Deploy from a branch，选择 `main` 和 `/ (root)`，保存即可。更新时提交变更后的文件。

## 资源

现有 9 张本地 WebP 手绘图。01/01 的 `maps/day-7.webp` 尚缺，页面使用可点击的路线列表代替。实景照片通过外部链接加载，加载失败时隐藏图片区域。
