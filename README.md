# 香港与南洋 · 双人旅行手记

2026/12/25—2027/01/03，两个女生的深圳、香港、槟城与马来西亚 10 日旅行计划。纯静态页面，无须编译。

## 本地运行

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

## 手机端结构

- **行程**：首页杂志封面 → 日期选择 → 每日景点封面 → 手绘路线总览 → 时间轴与交通 → 具体餐厅 → 景点攻略。
- **发现**：备选景点与餐厅，支持城市、类型和关键词筛选。
- **账本**：两人人民币规划预算，可修改并自动汇总。
- **准备**：机酒、按时间或类别排列的待确认事项、行李清单。

不再保留独立地图页。手绘图直接放在当天详情前，支持全屏查看与 PNG 下载。酒店、预算、确认事项和行李勾选保存在浏览器 localStorage。

## 餐厅资料与核验状态

餐厅数据集中维护在 `restaurants.js`，日程和备选库使用同一套餐厅卡片。

- 已用有名称的餐厅替代「附近简餐」「本地烧腊」「粥面店」等泛指。部分连锁仍需落实具体分店；集中列入「准备 → 待确认 → 餐饮」。这是候选餐厅清单，不是已核实门店、路线与营业状态的定稿。
- 菜单是两人点单建议，并非已获取的实时菜单。
- **人均预算**属于行程规划，不冒充平台实际人均。首次默认餐费按两人和页面规划汇率同步到账本；已保存的用户金额不被此步骤覆盖。
- **营业参考**来自原行程里已有的时段，未经本次联网核验；新增候选店未移用别家餐厅的营业时间。缺少时段的卡片提供门店查询入口。
- 优先采用大众点评；无法取得时可采用 Google Maps。两平台评分独立存储，默认为 `null`，只有同时具备有效数字、对应平台 HTTPS 来源链接和核验日期才显示。卡片标明平台与核验日期，不混用分数；当前尚无已核验评分，提供 Google Maps 与大众点评查询入口。
- 门头图只接入原资料中带具体店面出处的候选图片（如 Ivy’s、Nancy’s、Tek Sen、Jonker 88 及部分备选店）。没有用菜品、同类店铺或 AI 图片冒充门头。其外链加载、店面对应关系和时效尚需核验。

当前云环境拒绝访问 Google Maps、大众点评、搜索引擎、图片站和 GitHub Pages 域名，返回网络代理 `403 Forbidden`。所需域名已添加到环境配置草稿，保存该草稿不会自动开放当前机器网络；需在环境设置中保存网络配置并发布，再重试资料核验。网络配置开放后，还需处理大众点评可能要求登录或验证码的问题。

需要补齐的各城市门店、评分、营业、人均和门头任务统一放在「准备 → 待确认」，页面其他位置不重复铺免责声明。
